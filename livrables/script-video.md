# Script vidéo — Calculatrice .NET MAUI (15 s)

Mode d'emploi : enregistrement écran du téléphone en **portrait**, une seule prise, 15 secondes chrono. Points nommés d'écran en fond neutre.

| T | Plan | Action |
| --- | --- | --- |
| 0–2 s | Nom de l'app | Onglet « Calculatrice », écran vide. Appuyer une fois sur un chiffre pour montrer la saisie fluide |
| 2–6 s | Opérations de base | Saisir `2 + 3 × 4 =` → l'opération apparaît **au-dessus** et le résultat `14` s'affiche (priorités respectées). Enchaîner `( 4 − 3 ) × ( 8 + 1 ) =` → `9` (parenthèses) |
| 6–9 s | Mode scientifique | Touche `2nde` : saisir `sin(90)` → `1` ; basculer **Deg → Rad**, saisir `sin(π÷2` → `1` ; puis `√9` → `3` et `10^(3)` → `1000` |
| 9–12 s | Fonctions pratiques | `200 + 10 %` → `220` (pourcentage contextuel) ; montrer `0,1 + 0,2 = 0,3` ; bouton `Copier` |
| 12–15 s | Mémoire + historique | `MS`, saisir `3 ×` puis `MR` → `30` ; ouvrir `Hist`, toucher une entrée pour rappeler un résultat ; finir sur une rotation du téléphone (mode paysage : le clavier reste entier) |

Conseils :
- Faire les gestes franchement pour que chaque pression soit visible.
- Cadrer en plein écran, sans barre système.
- S'arrêter pile sur le plan final (paysage + « = » affiché).

Scientifique · Mémoire · Historique · Paysage »*
